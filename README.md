Vice Ledger — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5 (1 platinum, 2 gold, 6 silver, 46 bronze). Every guide is written in our own words and cites dated sources: 121 dated citations across the 55 trophies, a 5-phase roadmap to the platinum showing every trophy with its key fact, 9 missable trophies flagged with save advice, filters by kind and grade, search, a spoiler-safe mode that hides story trophies until earned, saved progress with export and import, and a Sources & Audit tab with the full source matrix. It runs entirely offline from its own static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/ in desktop Chrome. No build step, no network needed — the app loads only its own files.
